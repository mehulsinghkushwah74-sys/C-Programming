# C Programming Practice &amp; 
Learning Journey  Welcome to my personal C programming repository. This repository serves as a structured archive of the programs, lab exercises, and algorithmic practice problems I have written while learning C programming fundamentals.

📂 Repository Structure
Basics & Syntax: Variables, standard data types, arithmetic/logical operators, and basic console I/O (printf, scanf).
Control Flow: Decision-making statements (if-else, switch-case) and loops (for, while, do-while).
Functions & Modular Code: Custom functions, parameter passing, and recursion.
Arrays & Strings: 1D arrays, 2D matrix operations, and null-terminated string manipulation.
Pointers & Memory: Pointer arithmetic, call-by-reference mechanisms, and dynamic allocation (malloc, calloc, free).
Structures & Unions: Custom composite data types using struct and typedef.
File Handling: Reading and writing data streams via file pointers (fopen, fprintf, fscanf, fclose).

🛠️ How to Compile and Run
To run these programs locally, ensure you have the GCC compiler installed on your system.
On Windows
Open Command Prompt or PowerShell inside the target folder:
# Compile
gcc filename.c -o program
# Run
program.exe

On Linux / macOS
Open Terminal inside the target folder:
# Compile
gcc filename.c -o program
# Run
./program
